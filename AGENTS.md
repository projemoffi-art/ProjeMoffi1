Never run git checkout, git restore, or git reset on any file without the user's explicit prior approval for that specific action — no exceptions. If a script or edit produces unexpected, incorrect, or incomplete results, do NOT use git to discard the change. Instead: (1) rewrite the file's correct content in full using a write/overwrite operation, or (2) manually fix only the specific incorrect lines. If genuinely unsure how to proceed, stop and ask the user before touching git.
